# App User Flow

1. Onboarding
   - Intro screen
   - Permission request: Screen Time
   - App group selection

2. Dashboard
   - Daily usage chart
   - Goal progress ring
   - Countdown to limit

3. Limit Setting
   - Choose app group
   - Set time per day
   - Toggle blocking on/off

4. Alerts
   - Local notifications
   - In-app warning modals

5. Paywall
   - Triggered after using 1 free group
   - Offers annual premium

6. Premium Dashboard
   - Extended analytics
   - Motivational tools
