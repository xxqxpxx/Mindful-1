# Detox – Screen Time Control App (Brainrot Clone)

An iOS SwiftUI app that helps users reduce screen time by blocking addictive apps, tracking usage, and offering gamified progress.

## Core Features
- Screen time tracking
- App group blocking
- Daily limit setting
- Progress dashboards and streaks
- Confetti win animations
- Paywall with premium analytics
- Push alerts on overuse

## Tech Stack
- Swift 5
- SwiftUI + MVVM
- Combine
- Core Data
- FamilyControls, ManagedSettings, DeviceActivity
- Superwall (paywall)
- StoreKit 2 (subscriptions)
- Firebase (analytics)
