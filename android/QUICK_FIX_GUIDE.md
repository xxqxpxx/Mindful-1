# Quick Fix Guide for App Selection Issues

## 🚨 **If you're seeing -1 values or apps not showing:**

### **Step 1: Check Permissions (Most Important)**
1. Go to Android **Settings** → **Apps** → **Awaytime**
2. Tap **"Permissions"** 
3. Look for **"Usage access"** - make sure it's **ON**
4. If you don't see it, go to **Settings** → **Special app access** → **Usage access**
5. Find **Awaytime** and turn it **ON**

### **Step 2: Re-select Your Apps**
1. Open Awaytime
2. Tap **"Select Apps"** on the dashboard
3. If the screen is stuck loading, tap the **refresh button** (↻) in the top right
4. Choose your apps (Instagram, TikTok, etc.)
5. **IMPORTANT**: Tap **"Save"** and give it a name like "Social Apps"
6. Wait for the confirmation and go back to dashboard

### **Step 3: Wait for Data**
- Usage data takes 1-2 minutes to appear
- Use one of your selected apps for a few minutes
- Check if the dashboard updates

### **Step 4: Use Debug Console (If Available)**
1. If you see a **"Debug Console"** button on dashboard, tap it
2. Tap **"Auto-Fix"** - this resolves most issues automatically
3. Then tap **"Full Report"** to see what was fixed

## 🔧 **If App Selection Screen Won't Load:**

### **Method 1: Permission Reset**
1. Android **Settings** → **Apps** → **Awaytime** → **Permissions**
2. Turn **OFF** "Usage access"
3. Turn it back **ON**
4. Open Awaytime and try again

### **Method 2: Force Stop and Restart**
1. Android **Settings** → **Apps** → **Awaytime**
2. Tap **"Force Stop"**
3. Open Awaytime again
4. Try selecting apps

### **Method 3: Clear App Cache (Safe)**
1. Android **Settings** → **Apps** → **Awaytime** → **Storage**
2. Tap **"Clear Cache"** (NOT "Clear Data")
3. Open Awaytime and try again

## ⚡ **Quick Test:**
1. Select **Chrome** or **YouTube** (apps you use daily)
2. Set limit to **10 minutes** 
3. Use the app for 2-3 minutes
4. Check if dashboard shows usage

## 🆘 **Still Not Working?**

### **Nuclear Option (Resets Everything):**
1. Android **Settings** → **Apps** → **Awaytime**
2. **Force Stop** → **Storage** → **Clear Data**
3. Uninstall and reinstall from Play Store
4. Go through setup again

### **Device-Specific Issues:**

**Samsung:** Settings → Device care → Battery → App power management → Add Awaytime to "Never sleeping apps"

**Xiaomi:** Settings → Apps → Manage apps → Awaytime → Battery saver → No restrictions

**Huawei:** Settings → Battery → App launch → Awaytime → Manage manually → Enable all

## ✅ **Success Indicators:**
- App selection screen loads with apps visible
- After selecting and saving, dashboard shows "X apps selected"
- Usage numbers appear (not -1)
- Numbers increase as you use selected apps

## 📱 **Prevention:**
- Don't force-close Awaytime
- Keep "Usage access" permission enabled
- Always tap "Save" after selecting apps
- Give app groups meaningful names

---

**Most issues are permission-related. The "Usage access" permission is critical for the app to work.**
